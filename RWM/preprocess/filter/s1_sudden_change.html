S1 — Sudden Change

S1 是 Qwen-RobotManip-inspired 的 trajectory sudden-change evidence。它寻找“当前值显著偏离局部平滑趋势，并同时伴随剧烈动态变化”的 frame，用于定位关节、EEF、camera 或 observed action 中的短促跳变。

不是坏数据判定：S1 不检查 absolute value 是否越界、不检查 command-state agreement、不检查 FK，也不能区分 sensor glitch 与真实快速动作、接触、碰撞或急停。输出只用于 review 排序；当前不产生 KEEP/DROP、eligibility 或 readiness。

目标与非目标

S1 尝试捕获S1 不能证明
一帧或短时间的 joint jump、EEF/camera pose spike、motion delta 突变、短促控制抖动。该 frame 一定错误；整个 split/episode 应删除；canonical axes、camera、FK 或 command 已验证。
同一动态事件在 state、motion、joint、EEF 等不同表示中的候选响应。这些响应是统计独立证据；motion80 本身由 observed state 派生。
smooth example: 0.00, 0.01, 0.02, 0.03, 0.04
spike example:  0.00, 0.01, 0.50, 0.03, 0.04

跨数据集 General Requirements

下面是未来把 S1 应用于任意 robot dataset 时必须满足的稳定要求。具体 signal extractor、连续段规则和 threshold 属于 dataset/source-revision policy；AgiBotWorld-Beta 的数值不能直接复制到其他数据集。

RequirementGeneral contract
Stage 与 frozen inputS1 属于 FILTER。只读取 frozen canonical values、per-field masks、authoritative timestamps、continuity 和 exact ALIGN receipt；不在 S1 中修轴、换单位、补 pose、改时间或重写 canonical masks。
Signal inventory逐 dataset/source revision 声明要检查的 observed state、genuine command 或 training action view，并记录 producer、frame、origin、units、side/entity 和 control mode。State-derived motion 与 state 不是独立证据；离散 mode、button 和允许阶跃的 gripper 不能默认套用连续信号规则。
可比表示Joint/translation 使用冻结的物理单位；不同移动坐标系中的向量必须先用已有 canonical geometry 表达到同一 basis。只有 basis、world convention、camera role 和 flange/TCP origin 具有 compatible exact field verdict 的 strata 才能 component-wise pooled fit；未验证或不兼容的 strata 只能各自生成 evidence，不能共用 channel threshold。Rotation 在 SO(3) 上用 relative rotation/geodesic metric，禁止直接对 quaternion、Euler 或 packed Rot6D components 做普通差分。
时间与连续段每个 dataset profile 必须指定唯一 authoritative physical-time field；不得把 storage/header FPS 或任意 model clock 默认为物理时间。遇到 invalid endpoint、非递增时间、超阈值 gap、entity dropout、split/window 边界或 clean-segment change 必须断段；不得跨边界平滑、求导或连接事件。Boundary halo 只能来自同一连续 parent context，输出必须裁回原 selection unit。
Policy calibrationSmoothing、window、derivative order、minimum segment length、gap threshold 和 residual/dynamics thresholds 必须按 FPS/time regime、signal class、embodiment 与 source stratum 在代表性 calibration data 上冻结，再在 held-out data 审计。阈值必须带版本和 hash；论文未公开的参数不能标成 Qwen 原始设定。
Evidence scope最小 flag unit 是 entity + signal + channel + row/transition，同时保留 measured residual、acceleration/jerk、threshold 和连续 range，再向 split/episode 汇总。单帧命中、边界命中或多 derived views 同时命中都不能自动升级为独立的物理错误。

AgiBotWorld-Beta pilot 输入

S1 不对 packed Rot6D 分量做差。State joint 使用 canonical sidecar 内 preserved source-observed columns（代码字段 left/right_joint_state_raw）及其 exact masks，不绕过 sidecar 回读未绑定 source；EEF/camera 使用 sidecar 中的显式 world transforms。Motion joint 读取 motion80，motion EEF/camera 则先把 C[t-1] 中的 delta 旋转或共轭到统一 parent world basis，再做跨帧比较。

Jointleft/right observed joint position，共 14 channels。left/right motion80 joint delta，共 14 channels。
TranslationT_world_left_eef、T_world_right_eef、T_world_camera 的 xyz，共 9 channels。left/right EEF delta 与 camera delta 转到 world basis 后的 xyz，共 9 channels。

共 16 组 signals：4 joint、6 translation、6 rotation。每个 signal 使用自己的 validity；没有一张“所有字段同时有效”的总 mask。

Split、motion 与连续段

logical split frames/state = [s,e)
eligible incoming motion   = [s+1,e)

local row 0 ↔ canonical row s
motion80[s] = incoming edge s-1 → s  # crosses split left boundary
therefore local motion row 0 is force-masked in the FILTER view only

canonical values/masks 不修改。每个 channel 遇到 invalid mask、非有限 timestamp、非递增时间、dt>0.05 s、transition_contiguous=false 或 clean segment 变化时立即断段；S1 不跨这些边界平滑或求导。

每个 channel 的计算

1. 建立局部趋势

  1. 5-frame median filter，1 pass，用于压制孤立尖峰对趋势的影响。
  2. 7-frame、二阶 timestamp-space local polynomial/Savitzky–Golay smooth。
  3. 使用当前 Beta sidecar 的 model_time_sec。该 profile 没有另设 model grid：它是由 authoritative agibot.timestamp_ns 归一化得到的 video_time_sec 的 exact copy；因此这里仍是 physical-time derivative。未来 dataset 必须读取其 profile 指定的 authoritative physical-time field，不能照抄字段名。
raw:    x(t)
trend:  x_hat(t)

2. 三个 metric

residual(t)     = abs(x(t) - x_hat(t))
acceleration(t) = abs(d²x / dt²)
jerk(t)         = abs(d³x / dt³)
  • residual：当前值偏离附近趋势多少。
  • acceleration：信号弯折得多剧烈。
  • jerk：弯折的变化有多突然。

导数在 raw signal 上计算，因而会放大短促噪声。对于 state position，这些量接近物理 acceleration/jerk；对于 motion80 delta，它们是 action-delta 序列的高阶变化指标，不能严格等同于机器人真实物理加速度或 jerk。

3. Rotation 处理

Rotation 先转为 SO(3)，保证 quaternion xyzw 符号连续，再平滑并归一化。Residual 使用 geodesic angle；angular acceleration/jerk 来自相邻 rotation 的 relative rotvec 和 physical timestamp。Rot6D components 从不直接相减。

Provisional threshold 与 flag rule

Qwen-RobotManip 没有发布可直接移植到本数据的 numeric threshold。当前 pilot 把 10 个 long parent 的 178 个 split pooled，并对每个 signal/channel/metric 独立取 q99.5：

T_residual[channel]     = q99.5(residual)
T_acceleration[channel] = q99.5(acceleration)
T_jerk[channel]         = q99.5(jerk)

channel_flag = residual > T_residual
               AND
               (acceleration > T_acceleration OR jerk > T_jerk)

signal_flag = any(channel_flag)
S1 row flag = any(signal_flag)

Conjunction 的目的，是避免仅因“运动快”或仅因“偏离趋势”就命中；但真实接触、急停、控制振荡仍可能同时满足条件。阈值状态固定为 provisional / pilot_arbitrary_not_paper_specified。

当前使用方式与下一 gate

目前只把 S1 用作 review priority。优先级较高的是：远离 split 边界、连续多帧、state+motion 同时命中、joint+EEF 同时命中的范围。Camera-only、单帧和首尾范围降级处理。

  1. 从 parent 读取 7–10 frame context halo，保持 canonical gap/invalid boundary，不跨 clean segment。
  2. 只把结果裁回原 split [s,e)，与当前无-halo flags 做 stability comparison。
  3. 对 S1-only、与其他 evidence 共同命中、以及 clean control 做分层视频/轨迹复核。
  4. 在 stratified random corpus 与 held-out split 上冻结 policy 后，才讨论 selection reason 和 named-loss eligibility。
