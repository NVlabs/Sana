C2 — Video–State Consistency（TODO / BLOCKED）

C2 比较“由 URDF、recorded joint state 与 camera geometry 渲染出的机器人 silhouette”和“真实 RGB 中分割出的机器人 pixels”，用于发现 video、state、camera、time 或 robot model 之间的 cross-modal disagreement。

当前状态：TODO_DOCUMENTED / BLOCKED_NO_ROBOT_SAM_FINE_TUNE。项目目前没有可用且 hash-bound 的 robot fine-tuned SAM/SAM3 checkpoint，因此不能生成可信的 actual robot mask，也不能运行 C2 IoU。这里的 BLOCKED 是 pipeline-readiness 状态，不是任何 frame、split 或 episode 的坏样本 verdict。当前没有 C2 runner、per-frame/per-split C2 JSON、model invocation、threshold、selection 或 eligibility；不使用 generic SAM 结果冒充 Qwen C2 evidence。

Qwen-RobotManip 的 C2 流程

论文正文与 Figure 2 明确给出以下流程：

q[t] + URDF + camera[t]
  → render robot reprojection → M_render[t]

RGB[t]
  → fine-tuned SAM3 robot segmentation → M_rgb[t]

IoU[t] = area(M_render[t] ∩ M_rgb[t])
         --------------------------------
         area(M_render[t] ∪ M_rgb[t])

正文说 low-overlap samples 被过滤。Figure 2 进一步画出 IoU < threshold 时：若原因是 camera parameters，则优化 camera parameters；否则排除 episodes。

本项目 stage boundary：Camera optimization、joint/time mapping、URDF/tool correction 都会改变 canonical semantics，必须返回 ALIGN、升级 revision 并重建 sidecar。FILTER/C2 只能记录 disagreement、REVIEW 或决定 named-loss eligibility，不能现场优化后覆盖 canonical 数据。

当前 AgiBot robot data 已具备什么

2026-07-05 project decision 已接受 AgiBotWorld-Beta 与 AgiBotWorld2026 的 canonical mapping 和 exact sample visual packets，因此 canonical orientation 本身不再是 C2 的待决项。现有可复用输入/组件包括：

  • Beta G1_120s / 2026 G2 robot model、双臂 joint state、source-preserved waist/base fields；
  • head/top-head RGB、intrinsics、distortion、extrinsics 与 canonical frame mapping；
  • real_robot/qa_agibot_beta_geometry.py 的 URDF/joint/waist/FK mapping；
  • geometry_audit/loaders.py 与 unified_sequence.py 的 exact camera/RGB/projection contract；
  • filtering/agibot_beta_split_io.py 的 split、row、hash 与 accounting 框架。

这些组件尚不能组成 C2：现有 unified renderer 只投影 EEF triads，不生成 full-body silhouette；现有 SAM3 runtime source 没有 robot fine-tuned checkpoint、项目调用入口或 receipt。

当前 blockers

  5. TODO_C2_SCHEMA_TESTS：缺 per-frame evidence schema、mask/overlay artifacts、full accounting，以及 camera inverse、time shift、joint sign/order、wrong URDF/tool、distortion/crop mutation tests。

未来最小 pipeline 与输出

exact frame packet
  → validate decode/state/camera/URDF/model bindings
  → render M_render + visibility metadata
  → segment M_rgb with frozen robot SAM
  → IoU / precision / recall + reason codes
  → per-frame evidence
  → contiguous-window and split summaries
  → separately frozen named-loss selection policy

未来每个 frame 至少应区分 PASS、LOW_OVERLAP、INSUFFICIENT_VISIBILITY、SEGMENTATION_FAILED、RENDER_FAILED 和 INPUT_REJECTED。首轮必须 evidence-only、selection_effect=NONE；低 IoU 不自动等于 DROP。
