如何使用这个决定

  • 后续 FILTER 研究可以把五套数据的 canonical mapping 视为项目已接受的 frozen input；FILTER 仍必须核对 exact source/sidecar/schema/transform/hash，不能重新旋转、改相机或覆盖 canonical masks。
  • 本次 signoff 解决的是此前文档中的“视觉 signoff pending”；它不把未抽样 corpus、MASKED fields、robot TCP 或 command provenance 自动提升为 PASS。
  • 若需要标准字段 alignment_status=PASS 的 full-corpus release，下一步仍应把既有 corpus L0/L1 accounting、source L2 evidence 与本 hash-bound L3 decision 聚合成新的 strict receipt；不应回写旧 READY 或 reports。
  • ALIGN 仍不输出 training_ready。训练 eligibility、selection 与 L4 属于后续 FILTER。
