已确定：absolute state 是事实源，action chunk 在 dataloader 构造

Qwen-style EEF action 依赖当前 chunk 的起点，因此不存在一个与窗口无关的 per-row EEF action。相同 target row u 在窗口起点 s=0 与 s=5 下分别表示 E[0]→E[u] 和 E[5]→E[u]， 数值不同。新的 canonical source of truth 保存逐时刻 absolute state/geometry； dataloader 对每个窗口 [s,e) 生成 action tokens。 

canonical row t:
  q_abs[t]
  T_W_E[t]                 # canonical E axes and the declared EEF origin
  gripper_closedness[t]
  T_W_C[t]
  field masks, timestamps, transition continuity
  genuine_command[t]       # optional; only with verified producer/provenance

model window [s,e):
  current_state = state[s]
  targets       = state[s+1:e]

令 u=s+k，所有未来 token 使用同一个 current EEF E[s] 和同一个 reference camera C[s]：

action_joint[k]   = q_abs[u]
action_xyz[k]     = R_Cs_W @ (p_W_E[u] - p_W_E[s])
action_rotation[k]= rotvec(R_Cs_W @ R_W_E[u] @ R_W_E[s]^T @ R_W_Cs)
action_gripper[k] = gripper_closedness[u]
  • state[s] 是当前观测对应的 absolute state，不是 episode frame 0；下一次 replanning 使用新的观测重新 anchor。
  • Joint target 与 gripper target 为 absolute value；EEF xyz/rotation 为相对 current state、表达在 current reference camera C[s] 的 delta。
  • motion80 不再是 model action，也不是新 canonical 的必需训练事实源。若 verification/filter 仍需要 adjacent transition，可从 absolute states、camera poses、timestamps 与 continuity 确定性重算，或保留为明确标记的 derived audit artifact；模型不得读取它代替 current-anchored action。
  • Observed future state 与 genuine issued command 必须分开。当前预训练可以把 future observed state 作为 target trajectory；以后 command provenance 可靠时，另行选择 command target，不能静默覆盖 observed state。
  • Action mask 由 current/target field masks、reference camera validity、时间连续性和 strict clean span 共同决定；不跨 gap 或 invalid row。任一步 invalid 时不拼接其前后轨迹。
  • Normalization 必须在 current-anchored action 定义完成后重新统计；现有 adjacent-motion statistics 不复用。Action rotation 固定为 rotvec3，40D/per-arm token 中的具体 slots 仍需单独冻结。

已确定：state rotation 用 absolute Rot6D，action rotation 用 relative rotvec3

字段表示原因
Current state rotationR_Cs_Es 的 column-based Rot6D：[R[:,0], R[:,1]]State 是 absolute orientation，需要在完整 SO(3) 上稳定、连续地供网络回归；identity 为 [1,0,0,0,1,0]。
Future action rotationCurrent-anchored delta_R_Cs[k] 的 rotvec3 / axis-angleAction 是相对 current state 的局部变化；三维、identity 为零，适合作为 zero-centered action channel。
R_Cs_Es       = R_Cs_W @ R_W_E[s]
state_rot6d   = [R_Cs_Es[:, 0], R_Cs_Es[:, 1]]

delta_R_Cs[k] = R_Cs_W @ R_W_E[s+k] @ R_W_E[s]^T @ R_W_Cs
action_rotvec[k] = Log(delta_R_Cs[k])^vee

# closure
delta_R_Cs[k] = Exp(hat(action_rotvec[k]))
R_Cs_Etarget[k] = delta_R_Cs[k] @ R_Cs_Es
  • rotvec3 不是 Euler xyz。向量方向是旋转轴，L2 norm 是弧度角；使用 SO(3) principal log/shortest geodesic，角度范围为 [0,π]。
  • Rot6D 的两个三维向量解码时按 Gram–Schmidt 正交化，再以 cross product 得到第三列；不能把六个 component 当作独立欧氏角度解释或直接求差。
  • Current-anchored action 跨越多帧，角度可能明显大于 adjacent-frame motion。必须单独审计接近 π 的分支不连续和可能存在的 multi-turn 任务；不能复用旧 motion80 的角度统计。
  • Action normalization 在 rotvec3 构造完成后、以弧度为物理单位重新统计；state Rot6D 不与 action rotvec3 共享 rotation statistics。
  • Qwen paper 没有公开旧 6 个 rotation slots 如何压成 3 个 action slots。我们需要冻结新的 per-arm state/action schema；state projector 与 action projector 可以输入维度不同，不能靠保留三个无定义的 padding slots 来隐式决定协议。

Absolute EEF pose：axes 已 canonicalized，origin 仍需分开审计

T_W_E[t] = T_W_raw[t] @ T_raw_E
T_Ct_Et  = inverse(T_W_C[t]) @ T_W_E[t]

T_raw_E 的旋转部分把每套 source 的 EEF local basis 转成共同的 canonical E： +X physical approach、+Z signed jaw/opening、 +Y=+Z×+X。因此保存的 T_W_E、由它得到的 T_Ct_Et 以及 state80 Rot6D 都使用 canonical axes；dataloader 只改变 parent/reference frame 和 action anchor，不应再交换或翻转 EEF local axes。

T_W_F_fk[t]   = FK_URDF(q_urdf[t], base/waist[t])
