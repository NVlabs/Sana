S3 — Extreme Value

S3 是 Qwen-RobotManip-inspired 的 per-dimension distribution outlier filter。它检查 packed state/action value 是否落在同 embodiment、同 channel 的预期数值带之外，目的是避免极端值扭曲训练使用的 quantile normalization 或造成异常梯度。

不是物理合法性证明：S3 只判断“相对当前 corpus 分布是否极端”。常见但系统性的单位、坐标轴或 producer 错误可能通过；正确但罕见的任务姿态或快速动作也可能被命中。Source meaning、units、frames 和 packing 仍属于 ALIGN。

Qwen-RobotManip 方法

对每个 embodiment type 的每个 state/action dimension，跨 episode 汇总有效值并计算第一与第九十九百分位：

R = q99 - q1
lower = q1  - alpha * R
upper = q99 + alpha * R

channel_flag[t] = value[t] < lower OR value[t] > upper
row_flag[t]     = any(channel_flag[t])

论文按 frame 排除越界值，并明确豁免 gripper dimensions，因为开/关状态通常是双峰分布，不满足该 percentile 假设。论文没有公布可直接移植的 alpha；原文见 Qwen-RobotManip technical report。

跨数据集 General Requirements

S3 必须针对“实际要送入某个训练 loss 的 exact tensor view”建立分布，而不是对来源和语义混杂的全库直接拟合一组 band。以下要求适用于新的 robot dataset、schema 或 hardware stratum。

AgiBotWorld-Beta pilot 输入

S3 读取 exact packed state80/motion80 training slots，并使用各自 frozen canonical masks。Mask=false 的 slots 不参与 band fitting，也不会被 S3 伪装成有效数据；mask=true 且 non-finite 必须作为 L0 input defect 拒绝，而不是由 S3 跳过。当前 Beta motion policy 针对 authoritative timestamps 下的 contiguous、近 30 Hz per-transition displacement；它不能直接用于其他 dt/FPS strata。

Provisional band 与 split 输出

当前 pilot 将 10 个 long parent 的 178 个 action-config splits pooled 后拟合统一 per-channel policy，再逐 split 评估：

quantiles = [0.01, 0.99]
alpha     = 1.5

threshold_basis = pilot_arbitrary_not_paper_specified
evidence_only   = true

alpha=1.5 是本 pilot 的 provisional choice，不是论文公开参数。阈值在同一 10-parent 样本上拟合并回测，因此 flag rate 是 in-sample policy evidence，不是可外推的 full-corpus 坏数据率。

Policy 暴露出的两类尺度问题

1. Near-constant camera motion：band 过窄

camera delta X band ≈ [-1.641, +1.642] micrometers
camera delta Y band ≈ [-0.986, +0.988] micrometers
camera delta Z band ≈ [-1.678, +1.678] micrometers

Camera motion 的 q1–q99 span 接近数值精度尺度，因此微小量化/周期更新也会越界。Flagged camera delta 全部小于约 77.3 µm，多数小于 10 µm，且不少呈约 27-frame 周期；它们更像 near-zero channel 的 numeric jitter，而不是独立的物理坏轨迹证据。

2. Cross-task absolute state：band 过宽

不同任务/workspace pooled 后，一些 joint band 已扩到约 -7.4～6.6 rad，camera Z band 为约 0.509～1.602 m。因此 state 0 flags 主要说明当前 S3 对 absolute-state outlier 不敏感，不能替代 URDF joint limit、workspace、source-stratum 或 alignment checks。

已讨论完成的 selection direction

Decision：用户确认当前 1,036 / 69,245 的比例足够小，下一版 selection 可将所有 S3-flagged target rows 排除，不再为 camera micro-jitter 单独保留例外。

  • “排除”写入新的 filter eligibility/selection manifest；不删除或重写 canonical sidecar，不改变 canonical masks。
  • 训练 window 不允许跨 excluded row/transition 拼接。对于 motion supervision，任何包含被排除 incoming edge 的 window 均不可用。
  • 最终实施前仍须声明 named training loss、window length 和 reason precedence；不同 loss 的 eligibility 必须分别输出。
  • 当前 agibot_beta_qwen_s1_s5_10long_v1 artifacts 仍是 EVIDENCE_COMPUTED、selection_effect=NONE；本页记录的是下一版 policy direction，不伪称已经执行。
  • 1.50% 只属于 10-long in-sample pilot。Full-corpus 运行必须重新报告 row、transition、window、duration 和 task/source-stratum retention。
