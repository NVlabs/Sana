Sol-H3 generates MiniMax-H3 video with native audio faster than playback on one 8× NVIDIA B300 system. Sol-Engine × Sol-Attn brings sparse attention, fused kernels, fast multi-GPU communication, and parallel video decoding into one runtime.

Plug-and-play LoRAs

FastH3 is the default, not a requirement. Compatible MiniMax-H3 few-step LoRAs—including LightX2V’s open 4-step and 8-step Turbo LoRAs—use the same Sol-H3 engine.

01 · Sol-Engine

Make the whole system fast.

Sol-Engine keeps the model ready and coordinates GPU kernels, communication across eight GPUs, compilation, and video/audio decoding.

02 · Sol-Attn

Select the blocks that matter.

Sol-Attn scores key-value blocks as attention runs. Query-dependent thresholding selects the important blocks for sparse attention, while proxy scores cheaply account for the rest—all in one pass.

04
Six optimizations · one runtime

How Sol-H3 gets faster.

Sol-H3 speeds up attention, GPU kernels, multi-GPU communication, and video decoding. The benchmark uses its fastest configuration.

GPU kernels

Fuse repeated operations

Sol-H3 combines normalization, conditioning, position encoding (RoPE), and MLP work into fewer GPU kernels. This moves about 178 GB less intermediate data per GPU for a full model evaluation. Humanize and KDA supported this tuning.

Multi-GPU communication

Faster 8-GPU data exchange

Sol-H3 fuses packing, the all-to-all GPU exchange, unpacking, and merging. It sends query/key/value (QKV) data in INT8 and returns attention results in FP8, reducing communication among eight GPUs.

Sparse-attention setup

Fuse the setup work

Sol-H3 builds key/value summaries, block metadata, and the attention mask together. This cuts setup from 1.206 to 0.285 ms (−76.4%). Reusing query summaries also avoids about 400 small GPU launches per request.

1.206 ms0.285 ms
Sol-Attn

No separate routing pass

SOL chooses blocks and computes attention in the same pass, so it does not store a full score map or a separate block list in GPU memory.

Video decoding

Parallel VAE decoding

Eight GPUs decode video tiles in parallel, reducing latency from 7.55 to 1.16 s. Batching each clip’s tiles lowers it again to 0.602 s; the fastest profile batches VAE work globally.

Conditioning

Precompute AdaLN

Sol-H3 computes adaptive layer-normalization (AdaLN) values before denoising and reuses them from a cache at every step. This frees about 24 GB per GPU and avoids roughly 26 GB of GPU-memory reads per step without changing the output.
