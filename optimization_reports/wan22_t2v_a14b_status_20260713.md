## 四个方向的审查结果

### 1. 拓扑并行

- 当前 CP4 使用 4-way Ulysses；输入 QKV A2A 做异步 enqueue，输出使用 direct A2A，且复用 inference-only receive buffers。
- 已实现并通过 4 卡 NCCL/DeviceMesh preflight 的 `ring=2 x ulysses=2` 拓扑候选。
- 完整推理在 Ring Attention 路径失败，不是性能回归：该路径要求 `return_lse=True`，当前 native SDPA backend 不提供 LSE，且 flash-attn 不可用。因此没有把该拓扑误计入 benchmark 或最终版本。
- 后续真正有价值的方向是补齐支持 LSE 的 Ring Attention kernel，再重新比较 2x2 与 1x4；仅改变拓扑配置本身目前没有正向证据。

### 2. Kernel

- 已保留：fused self-QKV/cross-KV projection、compiled modulation/gated-residual block glue、compiled pairwise Q/K RoPE。
- 已测试但拒绝：compiled full QKV+norm/reshape/RoPE（约 +1.5%）、compiled FFN（约 +3.1%）、compiled FFN epilogue（约 +4.2%）。这些候选虽然算子融合成立，但编译/dispatch/寄存器压力抵消了小算子收益。
- 已测试但拒绝：packed QKV A2A（78.105s，约 +3.3%）、source buffer reuse（77.514s，约 +2.5%）。当前 3 路异步通信的 overlap 比单次 packed exchange 更有效。

### 3. Attention

当前已经有 Attention 相关优化，但不是替换成稀疏 Attention：

- 已保留：Q/K RoPE 编译、QKV projection fusion、QKV A2A overlap/direct output A2A，以及 cross-KV invariant cache。
- 已测试但拒绝：native Flash self-attention、native cuDNN SDPA、compiled native SDPA；其中 compiled native SDPA 为 77.345s，约比 Full OPT 慢 2.3%，且保持 dense attention。
- 因此当前 Attention 仍是 dense exact path；没有引入稀疏、近似或改变质量语义的 Attention。

### 4. Cache

- 当前保留 EasyCache threshold 0.30：它是整体收益的重要来源，并且有既有视觉/帧一致性证据。
- EasyCache threshold 0.35：77.895s，但出现 81/405 帧差异，拒绝。
- 保守 TaylorSeer：134.548s，5 个 prompt 均 0/40 reuse，拒绝。
- TeaCache threshold 0.05：89.083s，仅 9/40 reuse（22.5%），拒绝；证据 run 为 `runs/20260713-133924-wan22_t2v_a14b_teacache_005_fused_invariant/outputs/benchmark.json`，job `4982073`。

Wan2.2 这里不是 token-routed MoE；两个 transformer 是按 denoising 阶段选择的两套完整模型，`high_noise/low_noise` 是阶段角色，不应按专家路由、跨专家搬运或 CPU offload 的方向继续优化。当前也没有降低显存的目标。

## 已完成与未纳入项

已完成拓扑、Kernel、Attention、Cache 四类候选的实现/运行验证，并只累计有正向且满足精确性约束的项。当前没有新的正向候选可以加入 Full OPT；因此最终版本仍为 75.597s / 1.707x。下一阶段若继续投入，优先级是支持 Ring Attention 所需的 LSE kernel，其次才是针对 GB200 的通信/计算 overlap 深挖。
