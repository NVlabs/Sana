S2 — State–Action Trend Alignment

S2 检查一条独立记录的 issued action/command 是否在时间上领先或同时于后续 observed state response，并且两者的运动趋势方向一致。它针对 action/state 时钟不同步、packet loss、错误配对和 channel mapping 问题，不是轨迹平滑度检查。

expected: action command[t] -- nonnegative response delay --> state change[t+d]

bad ordering: state changes before its recorded action
bad trend:    action increases while aligned state mainly decreases

独立性是前提：名称中叫 action 的 tensor 并不自动满足 S2。若 action 是从同一 observed state 相邻帧派生出来的，command-to-state agreement 会成为循环验证，不能发现原始 action/state 的时间错位。

Qwen-RobotManip 方法

论文对 state/action 共有的每个 joint dimension 分别执行：

  1. 平滑 state trajectory 与 action trajectory。
  2. 若 source action 是 delta parameterization，先积分恢复 absolute trajectory。
  3. 在 lag search window 内用 cross-correlation 寻找最佳 temporal lag。
  4. 对 lag-aligned 一阶差分计算 directional agreement（DA）：只在信号发生足够变化的时刻比较两边 derivative sign 是否一致。
  5. DA 低于 dataset-specific threshold 的 dimension 被标记；论文给出的典型阈值为 0.6–0.7，并按 episode 排除。
lag* = argmax_lag corr(action[t], state[t+lag])

DA = mean(sign(delta_action[t]) == sign(delta_state[t+lag*]))
     over active-change frames

在上面的符号约定中，合法 causal response 要求最佳 lag 表示 action 领先或与 state 同时；若最佳解释是 state 领先 action，则不满足 S2。论文没有发布可直接移植的 smoothing kernel、lag window 和 activity epsilon，必须按 source FPS、控制模式与执行延迟冻结 dataset-specific policy。原文见 Qwen-RobotManip technical report。

跨数据集 General Requirements

S2 是条件性检查，不是每个 dataset 都必须产生数值结果。只有 genuine issued command 与后续 observed response 的 producer、语义和时间关系都可证明时才是 APPLICABLE；其他情况必须按原因 fail closed，不能把所有缺证据都笼统写成 NOT_APPLICABLE。

为什么 AgiBotWorld-Beta 是 NOT_APPLICABLE

Beta source 中存在若干名为 agibot.action.* 的 candidate，但当前 adapter evidence 表明 joint/EEF candidate 是 state-filled 或 index-resampled，不能作为独立 issued command；gripper producer/issuance semantics 也未冻结。当前 exact canonical profile 因此明确“不提供可用于 S2 的 genuine command”，command80 全部保持 zero with mask=false，所以本 scope 为 NOT_APPLICABLE。如果未来 source revision 声称发布 genuine command 却缺 provenance/clock contract，则应是 INPUT_REJECTED/REVIEW_REQUIRED，不能继续沿用这个 N/A。

启用 S2 所需的下一 gate

  1. 确认每个 joint action field 是 genuine issued command，而不是 observation、post-hoc target copy 或 index-resampled state。
  2. 冻结 issuance timestamp、observation timestamp、control mode（absolute target、delta、velocity 或 effort）、units、per-dimension masks 与预期 actuator delay。
  3. 以 action-config split 为评估单位，不跨配置、gap 或 clean-segment boundary；搜索双向 lag 用于诊断，但 causal pass 只允许 action lead/coincide。
  4. 对运动事件不足的 idle/short split 输出 insufficient evidence，而不是用大量 0==0 造成虚假高 DA。
  5. 在 stratified calibration 与 held-out splits 上冻结 smoothing、lag window、epsilon 和 DA threshold 后，才讨论 split-level REVIEW/DROP policy。
