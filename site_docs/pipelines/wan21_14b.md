# Wan2.1-T2V-14B

Wan2.1-T2V-14B is the 14B dense text-to-video path in Sol-Engine. The optimized
configuration runs single-GPU with kernel compilation, EasyCache, and
**SOL Attention** (`techniques/sparse_backends/`).

## Speed

Full optimization uses compile + EasyCache + SOL Attention and reaches **3.48x**
speedup (563.8s → 161.8s). Measured warm on a single GB200 with 720x1280,
81 frames, 50 denoising steps, warmup excluded.

## Launch

```bash
# baseline (vanilla diffusers WanPipeline, single GPU)
python3 scripts/launch_candidate.py candidates/wan21_14b_baseline.toml --mode sbatch --confirm-submit

# optimized (~162s, 3.48x)
python3 scripts/launch_candidate.py candidates/wan21_14b_fullstack.toml --mode sbatch --confirm-submit
```

The optimized candidate enables kernel compilation, EasyCache, and SOL Attention
together; every technique is env-gated (all flags off = byte-identical baseline).

## Techniques

- [Cache](../techniques/cache.md): EasyCache reuses denoising work.
- [Kernel fusion](../techniques/kernel.md): compiled DiT glue with invariant caches.
- [Sparse attention](../techniques/sparse.md): **SOL Attention** block-sparse
  video self-attention (density 0.15) with dense guards on the first layer and
  the first denoising steps.
