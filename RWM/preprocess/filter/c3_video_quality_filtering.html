C3 — Video Quality Filtering

C3 检查训练视频的基本可用性与时间冗余：black frame、corrupted frame、blurred frame 和 prolonged static segment。静止段必须同时参考 RGB change 与 proprio activity；视觉变化小本身不能证明数据冗余。

当前状态：IMPLEMENTED / EVIDENCE_COMPUTED / MANUAL_REVIEW_PACKET_READY / PROVISIONAL_POLICY_V1。AgiBotWorld-Beta frozen 10-long scope 的 10/10 parent head video 已 full decode，178/178 split 各有独立 C3 JSON；另已生成 112 对可直接查看的同名 MP4+JSON。当前严格保持 selection_effect=NONE，没有 KEEP/DROP、eligibility 或 L4 readiness。

Qwen-RobotManip 明确写了什么

  1. 通过 image-processing checks 识别 black、corrupted、blurred frames 和 prolonged static segments。
  2. 静止冗余判断联合使用 image 与 state/action signals；论文指出这类冗余常出现在 episode 开始或结束。
  3. 保留 task-critical key frames；论文明确举例 gripper closure，避免删掉视觉变化很小但语义重要的 transition。

原文没有说所有静止段都坏，也没有说一帧 blur 就删除整个 episode。论文见 Qwen-RobotManip technical report。

AgiBotWorld-Beta v1 pipeline

frozen S1–S5 10-long scope manifest
  → re-verify 10 exact parents + 178 split IDs/hashes
  → bind canonical head RGB member to source ZIP member
  → SHA-256 source MP4 + exact sidecar
  → ffmpeg 7.0.2 full sequential decode (74,980 frames)
  → resize each frame to 160×120 RGB
  → reset edge/event state at every official split [s,e)
  → black / blur / visual motion metrics
  → normalized observed proprio activity from motion80
  → prolonged static + gripper open/close protection
  → one qwen_c3_video_quality.json per split
  → summary / run manifest / inventory; atomic publish

视频按 parent 只 hash/decode 一次；C3 仍严格按用户指定的 split episode 处理，任何静止 range、视觉 edge 或 gripper guard 都不跨 split。74,980 个 parent frames 中 69,245 帧属于 action splits；其余 5,735 帧明确记为 outside-split，不参与本轮 C3 verdict。

Provisional v1 policy

EvidenceCurrent threshold/profile
Black candidateBT.601 luma mean ≤ 8，或 luma≤16 的 pixel fraction ≥ 0.98。
Blur candidate160×120 luma 上 OpenCV Laplacian variance ≤ 20。
Visual low motionAdjacent-frame gray mean absolute difference ≤ 1.0（0–255 luma scale）。
Proprio low motion每个有效 group 的 magnitude 除以 frozen group threshold 后取 max；normalized max ≤ 1.0，且至少 4/8 groups 有效。
Prolonged staticvisual-low AND proprio-low 连续至少 60 frames = 2.0 s；不跨 split/gap/invalid edge。
Gripper eventObserved closedness cumulative excursion ≥ 0.1，连续确认 3 帧，step epsilon 0.001；保护前后各 15 帧（0.5 s），并裁到同一 continuous segment。
Normalized proprio groupScale corresponding to ratio=1
Left/right joint max |Δq|各 0.002 rad/frame
Left/right EEF translation norm各 0.001 m/frame
Left/right EEF rotation angle各 0.005 rad/frame
Camera translation norm0.0005 m/frame
Camera rotation angle0.002 rad/frame

这些数值不是 Qwen 论文参数。它们尚未经过 labeled sharp/blur、legitimate dark scene、waiting/contact/static truth 的 held-out calibration，因此只产生 candidate evidence。

如何解读 0 black / 0 blur 与 4,438 static

  • 0 black/blur 不是 PASS：只表示没有越过当前阈值。尤其 blur threshold 比实测 minimum 低很多，需要 labeled blur calibration 才能决定是否过于保守。
  • Static 不等于坏数据：34/43 段在 split interior，不能套用“只 trim 开头结尾”的假设。需要看对应动作、接触/等待状态和训练 loss。
  • Gripper protection有效：如果直接按 prolonged-static 删除，会误伤 501 个已检测到关键 open/close guard 内的帧。
  • 当前没有 clean-segment selection：static_unprotected 是保护后剩余 evidence；保护会把一个 ≥60-frame 原段切成短片段，不能再把每个碎片独立解释为“持续 ≥2 秒”。
